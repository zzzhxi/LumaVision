# LumaVision

参考 MeiGen 的提示词画廊与编辑流程制作的独立中文图片／视频提示词网站，采用柔和渐变背景、轻量侧栏与瀑布流作品展示。当前源码保存在构建1号 GitHub 账户（`zzzhxi`）的仓库 [zzzhxi/LumaVision](https://github.com/zzzhxi/LumaVision)，目前为公开仓库；本页记录本地运行、测试和仓库边界，协作说明 `AGENTS.md` 仅本地保留，不随仓库分发。

## 启动

在项目目录运行（Node.js 20.11+）：

```powershell
node server.mjs
```

打开 http://localhost:5173 。不需要安装依赖或构建。服务器只监听本机 127.0.0.1，不暴露工作文档。

部署到 Linux 时，参考 [单机部署说明](deploy/README.md)。配置 `LUMA_PUBLIC_ORIGIN` 后，服务只接受指定的 HTTPS 来源与 Host、使用 Secure 会话 Cookie、关闭演示验证码，并只按 `ADMIN_EMAILS` 授予管理员权限；此时必须同时配置绝对路径 `LUMA_STORAGE_ROOT`，邮件凭据由服务环境变量提供，未配置时发码接口返回 503。本地模式仍沿用 `mail.local.json` 和原有回环限制。模板适用于域名根路径的独立 HTTPS 站点；部署在共享域名的子路径时，还需由 Nginx 统一改写首页资源、API 与媒体地址，不能直接套用独立站点配置。

公开仓库只包含源码、静态资源、测试、脚本和构建配置。用户作品、账号会话、上传媒体、生成原图、私有邮件配置、运行日志、依赖缓存和构建产物不随仓库分发；部署站点与本地文件存储也不会自动同步。

## 功能

- `data.js` 当前为空示例数组，公开画廊展示来自网站数据的作品；`assets/` 仍保留本地参考照片与来源说明，照片不是提示词的实测输出。
- 账号体系：点击「开始使用」打开欢迎弹窗。注册时输入邮箱前缀并选择支持的邮箱后缀，获取 6 位验证码，验证后设置密码并填写图形验证码；仅支持 163、QQ、Gmail、Outlook、126、Hotmail 常见个人邮箱。登录只需完整邮箱和密码。首次注册后选择「个人用户 / 创作者」；个人资料页可凭邮箱验证码修改密码，忘记密码时可通过邮箱验证码重置。会话持久化；暂不接入微信和 Apple。
- 我的作品发布入口：侧栏底部不再显示发布按钮；创作者账号进入「我的作品」时，页面标题区域右上角显示「发布作品」。未登录、个人用户及其他菜单不显示该入口；申请中的创作者仍需通过审核才能发布。
- 个人资料管理：头像、自定义昵称、邮箱展示与社交主页链接（Instagram、X、Threads、TikTok、YouTube、Facebook、Pinterest、Behance、DeviantArt、Ko-fi，仅接受对应官方域名的 https 链接）。
- 个人主页（`#user/用户ID`）：公开展示昵称、加入时间、社交主页链接与已通过审核的作品；作品详情与卡片上的作者可点击跳转。
- 作品审核：发布作品需要审核通过的创作者身份。注册后的身份设置中选择「创作者」并至少填写一条社交主页（也可在个人资料页随时申请），管理员在「管理后台 → 创作者申请」中通过或驳回申请（驳回需填写原因，驳回后可修改重新申请）。上传与修改的作品先进入「待审核」，管理员通过后公开展示，驳回需填写作者可见的原因，驳回后修改可重新提交。本地 Node 服务可由首位注册用户成为管理员，或用 `ADMIN_EMAILS` 指定；Sites 不自动授予首位用户管理员权限。
- 左侧导航「最近更新」视图：仅展示上传的作品，按最近创建/更新倒序；手机端不显示该入口（内容可在「我的作品」查看）。
- 关键词、类型、分类、模型联合筛选；精选、最新、收藏热度排序。模型筛选统一走画廊顶部的快捷模型按钮。
- 全屏图片详情：作者与模型、收藏、分享链接、下载、提示词展开、相关作品。
- 桌面左侧导航与全宽瀑布流画廊；手机采用顶部分类导航。
- 卡片可使用创意进入创作弹窗；模型快捷筛选与清除筛选入口，详情和创作窗口提供提示词复制。
- 卡片作者下方显示社交主页的用户名（例如 `@creator_handle`）；收藏右侧提供社交平台按钮，新标签直达创作者主页。多个主页优先 X，无主页不显示入口；使用创意按钮加大。
- 收藏、创作台与已发布作品列表；「创作台」提供草稿、生成记录、我的投稿三分类。我的投稿仅展示本人在创作台生成、随后审核通过并发布到灵感库的图片作品，普通上传不计入。
- 创作类型与模型联动、比例选择、风格片段、TXT 导出、移除与短时撤销。
- 发布提示词与生成的图片／视频；支持一次多选、拖放、预览、移除附件、前移和设为封面。
- 上传作品展示多图相册和带播放控件的视频；支持再次编辑及上传进度、失败后重试。
- 普通作品卡片：管理员提供「下架」，必须填写 200 字以内的原因；创作者的本人作品提供「编辑」和「下架」，本人下架不要求原因。下架后从公开画廊撤下。
- 我的作品状态筛选包含草稿、审核中、审核驳回、作品下架；作者可查看下架原因、编辑保存并保持下架、删除/撤销或重新提交审核。管理员可在后台清理已注销作者的下架作品；管理员下架自己的作品仍必填原因，下架后可作为作者管理。下架媒体保留既有作者/管理员读取规则。无归属历史作品公开时沿用登录用户管理规则，下架后不允许任意账号编辑或删除。
- 可以粘贴提示词，也可以导入 `.txt` / `.md` 文本文件。
- 响应式画廊、原生 dialog 焦点管理、Escape 关闭、`/` 聚焦搜索、减少动态效果偏好。

## 账号与作品审核

本地 Node 版注册时输入邮箱前缀并选择后缀，再填写收到的 6 位验证码、登录密码和图形验证码。默认后缀为 `163.com`，也可选 `qq.com`、`gmail.com`、`outlook.com`、`126.com` 或 `hotmail.com`。服务端在发码和最终注册时均检查域名；已有账号仍可使用完整邮箱登录和重置密码。邮箱验证码 10 分钟内有效且只能使用一次；每个邮箱 60 秒内只能发送一次，连续错误 5 次需重新获取，全站每分钟最多发送 20 次。图形验证码 5 分钟内有效、一次性使用；密码为 8 至 64 个字符且需同时包含字母和数字，服务端使用 scrypt 加盐哈希保存。

注册后可设置昵称与「个人用户 / 创作者」身份。个人用户可浏览、收藏、管理资料，首页隐藏发布按钮；选择创作者需要至少一条有效社交主页并提交审核，账号立即可用，审核通过后可发布作品。旧账号没有密码时，可在登录弹窗点击「忘记密码」，通过邮箱验证码设置新密码，身份、昵称、申请状态和作品归属保持原样；登录后在个人资料页也可凭邮箱验证码修改密码。个人用户也可在资料页申请创作者。会话以 HttpOnly SameSite=Lax Cookie 保存 30 天。

普通邮箱验证码可由 Gmail 发出。先为发信账号开启两步验证，再[生成 Google 应用专用密码](https://myaccount.google.com/apppasswords)（应用名称可填 LumaVision）；普通 Google 登录密码不能替代应用专用密码。项目使用 `smtp.gmail.com:465`、TLS 及证书验证。配置示例：

```json
{
  "AUTH_EMAIL_PROVIDER": "gmail",
  "GMAIL_USER": "你的发信邮箱@gmail.com",
  "GMAIL_APP_PASSWORD": "生成的16位应用专用密码",
  "AUTH_EMAIL_DEMO": "false"
}
```

将设置保存到本地 `mail.local.json`，重启 `node server.mjs` 生效；该文件不通过网页提供且已加入 gitignore。也可使用同名环境变量，环境变量优先。应用专用密码可保留 Google 显示的分组空格；缺少或格式错误时停止发信，不会退回演示模式。Gmail 的应用专用密码只用于 SMTP 发信，不启用网站 Google 登录。

也可使用 [Resend Email API](https://resend.com/docs/api-reference/emails/send-email)，切换 `AUTH_EMAIL_PROVIDER=resend`，启动前设置 API key 和已验证发信地址：

```powershell
$env:RESEND_API_KEY = '你的 Resend API key'
$env:AUTH_EMAIL_PROVIDER = 'resend'
$env:AUTH_EMAIL_FROM = 'LumaVision <login@你的发信域名>'
$env:AUTH_EMAIL_DEMO = 'false'
node server.mjs
```

完全未配置邮件服务时本地 Node 服务默认启用演示：页面明确显示「未发送邮件」及演示验证码。设置 `AUTH_EMAIL_DEMO=false` 可关闭演示；配置不完整时返回未配置错误，不会退回演示。公网模式即使环境要求演示也不开放该回退，缺少发信配置时返回 503；Sites 生产环境使用已验证的 Resend 发件域名并禁用演示验证码。本机 Gmail 曾通过真实收信验收；配置完整时验证码仅发送到邮箱，API 不回传验证码；发送失败不会创建账号或使旧验证码失效。本地验证码只以哈希保存在 `data/auth/codes.json`。

发布与修改作品需要登录。新发布和每次修改的作品都进入「待审核」，仅作者本人在「我的作品」可见（带状态徽标与驳回原因）；管理员在「管理后台 → 作品审核」页面通过或驳回，通过后作品公开展示，作者头像与昵称会链接到其个人主页。个人资料页可自定义昵称并维护社交主页链接，链接会展示在个人主页上。

管理员规则：本地 Node 服务可让首个注册用户自动成为管理员，也可在启动前设置 `ADMIN_EMAILS`（逗号分隔邮箱）。配置 `LUMA_PUBLIC_ORIGIN` 的公网模式关闭首位注册自动提升，仅按名单授权；Sites 版本只使用已有管理员角色或显式 `ADMIN_EMAILS`，不会因首位注册自动授予管理员权限。原账户的 Site 曾完成管理员邮箱替换；2026-09-30 当前账户的新私有 Site 按用户选择迁移本地副本，保留本地管理员身份及邮箱，未复制原线上邮箱替换状态。

### 本地管理后台

管理员可从账号菜单或主导航进入「管理后台」，切换用户管理、作品审核、创作者申请和生图服务。原 `#review` 链接会跳到 `#admin/works`；其他页签也可直接打开和刷新。

用户管理支持按邮箱、昵称或用户 ID 搜索，按角色、账号状态、创作者状态和账号类型筛选，并分页查看。账号详情可调整角色和创作者身份。停用会阻止登录并撤销现有会话和邮箱验证码；重新启用后需要重新登录。

注销前须输入完整邮箱确认。注销会撤销凭据、移除个人资料，并将作品作者显示为「已注销用户」。原邮箱可按现行规则重新注册，新账号不会继承原作品。原作品和媒体仍归原用户 ID；管理员可在「作品审核」清理已注销作者的下架作品。

导入作者档案只读。对 `ADMIN_EMAILS` 管理的账号变更角色、停用或注销前，须先修改环境变量并重启服务。管理员不能修改自己的角色、停用或注销自己；系统至少保留一个有效管理员。

## 上传作品

创作者账号登录后进入「我的作品」，点击标题区域右上角的「发布作品」；审核通过后可填写名称与提示词、选择图片或视频并点击「提交审核」，申请中的创作者点击入口会被引导查看申请状态。个人用户可在资料页申请创作者；管理员的审核权限独立于发布入口。可连续多次选择附件；第一项用作作品封面。审核通过后点击卡片即可切换多图、播放视频，并进入「编辑作品」；修改保存后作品会重新进入审核。没有附件时也可以单独发布提示词。

## 创作与发布

「创作台」右上角的「开始创作」打开提示词编辑窗口，下方按草稿、生成记录、我的投稿分类。编辑提示词、负面提示词、参考图与模型参数后可保存草稿，不会创建已发布作品。「使用创意」或「使用 Prompt」带入提示词与参数（草稿自身保存的参考图也会恢复）；「用作参考图」添加图片作为生成输入。

生成记录仅本人可见，记录中的「投稿到灵感库」把实际生成图片带入发布窗口，服务端校验来源后复制图片作为投稿附件，原生成记录保持私有。审核通过后进入「我的投稿」；审核中、驳回和下架作品在「我的作品」管理。普通上传及参考图不能标记成生成投稿；移除全部生成图片后，作品不再计入我的投稿。

生成记录的卡片与详情都提供「删除生成记录」，确认后由 `DELETE /api/generations/生成记录ID` 永久删除记录、原图与封面缩略图，无法撤销。已经用于投稿的记录是作品来源凭证，需要先在「我的作品」中下架并删除对应作品，否则接口返回 409 并提示原因。

### 启用本地图片生成

1. 启动本地生图服务和 LumaVision。用管理员账号登录，打开「管理后台 → 生图服务」。
2. 确认 API Base URL（默认 `http://127.0.0.1:38650/v1`），填写 API Key（接受纯 Key 或 `Bearer ` 前缀），点击「测试连接并读取模型」。
3. 勾选该服务上支持生图的模型，选择默认模型并保存。列表没有目标模型时可手填准确的接口 ID。连接测试只读取模型列表；实际支持的尺寸、数量和参考图格式由上游模型决定。
4. 打开「创作台 → 开始创作」，选图片模型和尺寸，填写提示词并生成。添加参考图时走图片编辑接口；没有参考图时走文生图接口。结果自动保存到当前账号的「生成记录」，可下载；创作者也可单独投稿审核。

密钥只保存在服务端的 `data/generation-config.json`（已被 `data/` 忽略规则覆盖）。留空保留原 Key，勾选清除并保存可关闭服务。不要分享该文件。视频生成未接入；Sites 仍使用独立部署，不能访问本机的 `127.0.0.1` 生图服务。

「发布作品」用于上传已经完成的图片或视频。创作弹窗的发布入口只带入文字与参数，参考图不会自动成为发布附件。参考图最多四张；本地选择的参考图刷新后需重新选择。详情链接采用 `#prompt/作品ID`，同一网站数据下可刷新恢复。

创作台草稿卡片显示来源封面或已保存的参考图预览；封面独立于生成参考图和发布附件保存，修改提示词或模型后仍保留。旧草稿可按来源 ID 或唯一相同提示词恢复封面，无图片的草稿显示文字。短页面的工作区填满可用高度，页脚位于底部。

创作草稿只显示在「创作台」，卡片提供编辑、移除与撤销。点击「开始创作」或「发布作品」每次都打开默认空表单；只有明确选择编辑或使用创意时才带入对应内容，关闭未保存的表单不会自动恢复。

新建发布窗口可「保存草稿」，允许名称、提示词尚未完整但已有内容或附件。发布草稿连同附件保存到本地服务器，只显示在本人「我的作品」，可刷新后继续编辑、保存、移除或撤销；草稿附件需要作者或管理员会话。补齐名称和提示词后「提交审核」，通过前不进入公开灵感库。已提交/已发布作品的编辑仍走原重新审核流程，不会直接改为草稿。

每件作品最多 12 个附件：单张图片不超过 20 MB、单个视频不超过 100 MB、总计不超过 200 MB。支持 JPEG、PNG、WebP、GIF、MP4、WebM；视频能否播放还取决于浏览器对其编码的支持，优先使用 H.264 MP4 或 WebM。

发布窗口只保留保存草稿与提交审核操作；提示词复制和 TXT 导出位于创作窗口。

「我的作品」顶部提供草稿、审核中、审核驳回状态筛选，可同时使用模型和图片/视频筛选。默认显示全部状态（含已发布作品）；再次点击已选状态或点击清除筛选恢复全部。其他页面保留精选、最新、最热排序。

卡片底部显示作者头像与昵称，下方左侧使用创意、右侧心形收藏和有管理权限时的编辑/删除；鼠标悬停或键盘聚焦显示按钮名称。卡片不再提供复制提示词按钮，详情和创作窗口仍可复制提示词。

提示词上限 8000 字，文本文件上限 100 KB。未发布的文本自动暂存在浏览器；已选附件在关闭再打开编辑器时保留于当前页面内存，刷新前需发布，刷新后需重新选择尚未上传的附件。

已发布作品保存到网站磁盘，刷新页面、关闭浏览器或重启服务后仍保留。保存采用原子元数据替换；重复重试不会重复创建作品，过期编辑会报冲突。移除作品会隐藏记录并提供短时撤销，原文件暂不自动删除；修改时移除的旧附件也保留于磁盘。

界面动效按 Motion Prompt 的 #049、#056、#057、#060、#074、#081、#086、#166 规格移植为站内 CSS/JS：覆盖弹窗、提示条、页签、筛选指示、卡片入场与悬浮、导航下划线和收藏反馈，保留原时长、缓动、MIT 署名与 `prefers-reduced-motion` 降级。创作台「我的投稿」按服务端验证的生成来源字段筛选；卡片接口保留 `generationMediaIds`，避免已审核投稿被漏掉。

## 产品边界

本地 Node 和 Sites 的 Worker/D1/R2 版本各自维护认证和存储，推送 GitHub 源码不会同步或部署 Sites。现有 Sites 部署使用邮箱验证码登录；本文的本地邮箱密码注册、注册域名白名单、用户管理和生图服务尚未同步至 Sites。两个 Sites 的部署源和验收记录保留在本机。上传的视频可以直接播放；示例照片来自 Unsplash，示例视频卡片为静态分镜参考。

本地 Node 版现有账号的密码哈希保存在 `data/auth/users.json`；密码哈希与邮箱验证码都不通过公开接口返回。收藏和未发布的文本草稿仍保存在当前浏览器的 localStorage 中；清除站点数据会清空这些浏览器数据，但不会删除已上传的作品。下载是否落盘由浏览器处理。

参考 https://www.meigen.ai/ 的浏览流程；品牌、布局、交互代码与提示词为独立实现，未复制源站代码和作品库。页面设置 noindex。Sites 部署与受众状态见本地验收记录。

构建1号账户的 GitHub 仓库仅保存项目源码、静态资源、测试和脚本，不是运行数据备份。推送前须保持 `data/`、`docs/`、`AGENTS.md`、`test-results/`、`mail.local.json`、日志、密钥、依赖缓存、构建产物和 `.openai/hosting.json` 部署身份隔离；这些本地记录、用户数据与私有配置不进入提交。
